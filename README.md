# AI-Based Recruitment Assistant Agent

##  Project Overview

AI-Based Recruitment Assistant Agent is an AI-powered recruitment support application that helps recruiters analyze candidate resumes and compare them with job descriptions.

The system extracts resume information, identifies relevant skills, performs skill-based matching, calculates AI semantic similarity, identifies skill gaps, and provides recruiter assistance.

The system is designed as a decision-support tool. Final recruitment decisions remain with human recruiters.

##  Features

- Resume PDF upload
- Resume text extraction
- Automatic skill extraction
- Job description analysis
- Skill-based candidate matching
- AI semantic matching
- Multiple candidate analysis
- Candidate skill-gap identification
- Candidate summary generation
- AI Recruiter Assistant
- Recruitment Insights Dashboard

##  AI Technology

The project uses:

- Python
- Streamlit
- Sentence Transformers
- all-MiniLM-L6-v2
- Scikit-learn
- Cosine similarity
- PyPDF
